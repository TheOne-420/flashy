# Introduction

Flashy is a smart flashcard app where you can compete with your friends

## Tech Stack

### Frontend

- **Next.js** – React framework for building full-stack web applications
- **Tailwind CSS** – Utility-first CSS framework for styling
- **shadcn/ui** – Reusable and accessible UI component library

### Backend

- **Node.js** – JavaScript runtime for services and APIs
- **Go** – High-performance services in a microservices architecture
- **PostgreSQL** – Relational database
- **Drizzle ORM** – Type-safe ORM for database management
- **BetterAuth** – Authentication and session handling

## Getting Started

First, run the development server:

```bash
npm run dev
# or
```
